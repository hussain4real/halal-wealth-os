# Domain docs

Halal Wealth OS uses a single domain context.

Before exploring a feature, read the root `GLOSSARY.md` if present
and any relevant decisions in `docs/adr/`. Read the existing decisions
in `docs/halal-wealth-os/ADRS.md` and consult the architecture and
invariants in `docs/halal-wealth-os/` when they apply.

If a glossary or ADR directory is absent, continue with the existing
docs. Add glossary entries or ADRs when a term or decision is resolved.
Use established domain terms in tickets, proposals, and tests.
Call out any conflict with a recorded ADR and name the decision
that would need to be revisited.
