# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to review the issue. |
| `needs-info` | `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The issue will not be acted on. |

When a skill names a triage role, apply the corresponding GitHub label.
