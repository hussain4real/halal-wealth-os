# Investment intent and retained decisions

Opportunities are plans, never holdings. A watchlist entry may have unknown
target and evidence. A proposal has an exact native-currency target and
conditional tranches whose amounts sum to that target. A user-entered maximum
allocation limits the plan. No price, offer, eligibility or religious status is
inferred from a name or earlier example.

Each opportunity revision retains its complete thesis, tranche keys, source
links, verification/review dates and correction reason. Currency remains fixed.
An unknown asset may be identified later; an identified asset reference remains
fixed so its classification and actual-event links cannot silently move to
another security. History links always refer to their retained version.

Tranches reserve through the existing GoalService and its shared account-wide
capacity rules. Users explicitly choose an open reserved goal in the plan's
native currency. Dedicated protection and existing emergency/goal reservations
remain excluded. Decision links point to unique actual goal reservations,
never a second cash balance. Releases use the same retained goal-release path.
Revising a tranche cannot reduce it below its active reservations or attributed
current actual spend, or hide an active tranche. A closed plan requires releases.

Later purchase and paid-subscription events are linked as existing facts. A link
does not call the posting or investment-recording service, and one actual event
cannot be attributed twice. Reversed or replaced events remain visible as
changed evidence and do not count as current spend. Plans and factual events
are separate even when an actual amount exceeds a former plan. Attribution is
original gross paid cash, including fees/tax, until reversed; later sale
proceeds or subscription refunds remain separate investment facts. This is not
net invested capital. Complete decision exports include exact owner-scoped
source reservation amounts/backing/releases and event amounts/reversal links,
so original commitments and current attribution can be reconstructed.

Currency-concentration warnings compare the proposed amount and existing native
currency exposure against a user-attributed portfolio reference expressed in
the plan currency. Thresholds, reference source, observation and review dates are
explicit. These are dated manual planning references, not live valuation or FX
conversions. Missing, future or overdue inputs cannot produce a reassuring
percentage. No threshold is supplied as financial advice.

Offer status, price and eligibility each retain independent official-source
attribution and verification/review dates. A source checkbox is an owner's
attribution, not a verification performed by this application. Missing or stale
evidence is unverified. Shariah guidance reads the exact asset reference's
current attributed assessments and never blocks factual recordkeeping.

The optional example import reads an explicit private JSON file outside the
checkout, requires confirmation and an existing owner, and invokes only the
plan service. It creates no users, cash, reservation, trade or holding. The
original private example is not bundled, seeded by default or published.
