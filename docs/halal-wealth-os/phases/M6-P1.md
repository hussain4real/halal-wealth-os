# M6-P1 - Statement import and safe data portability

**Milestone:** M6 - Controlled integrations and notifications
**Dependencies:** M5-P3. When crossing milestones, the previous milestone gate must also be accepted.
**Initial status:** PLANNED. Owner authorization and dependency acceptance determine readiness.

## Description

Import structured CSV data through preview, mapping and reconciliation rather than writing raw rows directly into balances.

## Goal

Reduce manual entry while preserving ledger invariants and traceable source data.

## Task checklist

- [ ] **M6-P1-T1** Define versioned CSV schemas and reusable adapters with date, decimal, currency and transaction-type mapping.
- [ ] **M6-P1-T2** Build upload limits, file-type validation, private storage and a dry-run preview with row-level errors.
- [ ] **M6-P1-T3** Require owner approval of the selected valid rows; commit the chosen batch atomically via existing services.
- [ ] **M6-P1-T4** Deduplicate by stable provider IDs when available and documented fingerprints otherwise; support re-upload safely.
- [ ] **M6-P1-T5** Model transfer and investment matches explicitly; flag ambiguity instead of inventing transaction relationships.
- [ ] **M6-P1-T6** Add CSV exports with formula-injection protection and reversal-based import correction.

## Acceptance criteria

- [ ] **M6-P1-AC1** Importing the same statement twice creates no duplicate postings or positions.
- [ ] **M6-P1-AC2** A malformed/ambiguous row appears in preview with a reason and never silently writes a guessed transaction.
- [ ] **M6-P1-AC3** A batch failure rolls back the selected batch; retrying it yields one consistent import result.
- [ ] **M6-P1-AC4** Correction uses linked reversals and preserves the original import/source reference.
- [ ] **M6-P1-AC5** A spreadsheet-formula payload is neutralized on export and User B cannot access User A upload or preview.

## Deliverables

CSV import pipeline; preview/mapping UI; deduplication; safe exports and correction workflow.

## Verification emphasis

Duplicate import, malformed rows, atomic batch, transfers, private files and formula-injection tests.

All applicable global invariants and the verification contract also apply. Use the run template to record observed evidence; a checklist tick alone is not proof.

## Scope exclusions

OCR, email access, broker trading APIs and silently inferred transfers.
