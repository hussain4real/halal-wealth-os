# M6-P3 - Opt-in reminders and notifications

**Milestone:** M6 - Controlled integrations and notifications
**Dependencies:** M6-P2. When crossing milestones, the previous milestone gate must also be accepted.
**Initial status:** PLANNED. Owner authorization and dependency acceptance determine readiness.

## Description

Deliver the existing deterministic action rules through explicitly configured channels.

## Goal

Notify once, at the right local time, without leaking financial details or creating duplicate bank reminders.

## Task checklist

- [ ] **M6-P3-T1** Add per-rule/channel opt-in, quiet hours, timezone and notification-detail preferences.
- [ ] **M6-P3-T2** Implement in-app and one approved email channel using an outbox and at-least-once-safe dispatch.
- [ ] **M6-P3-T3** Use stable deduplication keys, scheduled retry limits and a delivery audit trail.
- [ ] **M6-P3-T4** Handle missed deposits using actual matched transactions and configurable grace periods.
- [ ] **M6-P3-T5** Apply existing standing-order preference; do not enable deposit reminders automatically.
- [ ] **M6-P3-T6** Provide test-channel dry runs and a visible kill switch for external delivery.

## Acceptance criteria

- [ ] **M6-P3-AC1** A duplicate job creates one logical notification; retry does not duplicate delivery where the provider supports idempotency.
- [ ] **M6-P3-AC2** Disabled rules and quiet hours are honored at Asia/Qatar date boundaries.
- [ ] **M6-P3-AC3** A posted contribution matched to its schedule prevents a false missed-deposit alert.
- [ ] **M6-P3-AC4** External messages omit balances/holdings by default and respect the owner detail preference.
- [ ] **M6-P3-AC5** The kill switch prevents new external sends while preserving unsent outbox records for inspection.

## Deliverables

Notification preferences; outbox; delivery adapters; audit and deduplication tests.

## Verification emphasis

Outbox concurrency, timezone, quiet hours, matching, privacy defaults and kill-switch tests.

All applicable global invariants and the verification contract also apply. Use the run template to record observed evidence; a checklist tick alone is not proof.

## Scope exclusions

Unsolicited messages, new bank instructions, unlimited retries and unapproved communication channels.
