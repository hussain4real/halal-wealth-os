# M6-P4 - Personal Google Drive export

**Milestone:** M6 - Controlled integrations and notifications
**Dependencies:** M6-P3. When crossing milestones, the previous milestone gate must also be accepted.
**Initial status:** PLANNED. Owner authorization and dependency acceptance determine readiness.

## Description

Offer optional owner-initiated exports to a selected Google account and destination, without broad Drive access.

## Goal

Prevent accidental export to a school/work account and make data sharing deliberate.

## Task checklist

- [ ] **M6-P4-T1** Implement OAuth connection with an approved least-privilege scope and encrypted token storage.
- [ ] **M6-P4-T2** Display connected account identity and require explicit confirmation of the selected account/destination.
- [ ] **M6-P4-T3** Export a generated, owner-scoped report or backup through a queued operation with a content manifest.
- [ ] **M6-P4-T4** Use file-level access where sufficient; document any additional scope before requesting it.
- [ ] **M6-P4-T5** Add disconnect/revoke behavior, expired-token recovery and failure-safe export status.
- [ ] **M6-P4-T6** Keep public-link sharing disabled and separate export-to-Drive from application database backup policy.

## Acceptance criteria

- [ ] **M6-P4-AC1** The confirmation screen shows the actual connected email and target before upload; an unintended school/work account can be rejected.
- [ ] **M6-P4-AC2** Only the authenticated owner selected export is uploaded, with no public sharing permissions added.
- [ ] **M6-P4-AC3** Expired/revoked credentials fail safely, show reconnect guidance and do not leak tokens in logs.
- [ ] **M6-P4-AC4** Disconnect disables future exports and applies the documented token-revocation procedure.
- [ ] **M6-P4-AC5** Mocked tests pass without real OAuth credentials; an actual live export is not claimed until separately authorized and observed.

## Deliverables

Drive connector; account-confirmation flow; private export; revoke/reconnect tests.

## Verification emphasis

Account selection, owner isolation, permission payload, token expiry/revocation and failed upload tests.

All applicable global invariants and the verification contract also apply. Use the run template to record observed evidence; a checklist tick alone is not proof.

## Scope exclusions

Broad Drive scanning, automatic school-account export, public sharing and email ingestion.
