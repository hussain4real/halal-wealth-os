# M3-P1 - Assets and portfolio account modes

**Milestone:** M3 - Investments and valuation
**Dependencies:** M2-P3. When crossing milestones, the previous milestone gate must also be accepted.
**Current status:** READY_FOR_REVIEW, unaccepted. Local full, source, rendered and TIA gates pass; final publication/hosted checks and owner acceptance remain separate. The owner accepted M2-P3/M2 and authorized this phase through independent review, dev PR/normal merge and post-merge checks. At most six scoped cycles; one implementation writer.

## Description

Introduce instruments and portfolio organization without assuming every platform exposes individual trades.

## Goal

Represent detailed holdings or aggregate account value, never both in the same total.

## Task checklist

- [x] **M3-P1-T1** Create assets with type, currency, identifier, market and ownership-neutral reference metadata.
- [x] **M3-P1-T2** Support equities, unitized funds and manually valued investments; mark unsupported terms explicitly.
- [x] **M3-P1-T3** Create portfolio/account relationships and detailed-holdings versus aggregate-value modes.
- [x] **M3-P1-T4** Store quantities and unit prices as exact decimals with owner-scoped investment metadata.
- [x] **M3-P1-T5** Provide manual opening-position capture with an as-of date and known/unknown cost-basis flag.
- [x] **M3-P1-T6** Build asset and investment-account screens with clear source and valuation-mode labels.

## Acceptance criteria

- [x] **M3-P1-AC1** A fractional fund holding survives storage, display and export without cash-style rounding of units.
- [x] **M3-P1-AC2** An aggregate account value and its underlying assets cannot both contribute to net worth.
- [x] **M3-P1-AC3** Unknown opening cost basis is shown as unknown, not zero profit basis.
- [x] **M3-P1-AC4** A mode switch requires a reconciliation preview and cannot silently duplicate investments.
- [x] **M3-P1-AC5** Platform names are labels only; no broker connection, ownership or Shariah status is implied.

## Deliverables

Asset catalog; portfolio accounts; valuation-mode rules; opening-position interface.

## Verification emphasis

Fractional precision, aggregate/detail exclusion, unknown basis and account isolation tests.

All applicable global invariants and the verification contract also apply. Use the run template to record observed evidence; a checklist tick alone is not proof.

## Scope exclusions

Broker integrations, complex sukuk cash-flow modeling, derivatives and current-market assumptions.
