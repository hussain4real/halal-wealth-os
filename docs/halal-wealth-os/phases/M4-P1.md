# M4-P1 - Versioned Shariah assessment records

**Milestone:** M4 - Shariah evidence and investment decisions
**Dependencies:** M3-P3 and M3 milestone, human accepted.
**Status:** IN_PROGRESS, sole coordinator; cycle 4 of at most six.

## Description and goal

Preserve the authority, methodology, date and evidence behind each assessment
instead of using a permanent halal boolean. Keep compliance information
traceable, reviewable and appropriately uncertain. The application records
attributed assessments; it does not issue fatwas or certify securities.

## Task checklist

- [x] **M4-P1-T1** Create assessments with source/provider, methodology version, effective/review dates and supporting evidence references.
- [x] **M4-P1-T2** Support compliant, non-compliant, questionable and pending-review classifications plus conflict and overdue flags.
- [x] **M4-P1-T3** Separate business-activity and financial-screening findings without inventing unsupported thresholds.
- [x] **M4-P1-T4** Build an owner/admin evidence workflow with attributed revisions and retained assessment history.
- [x] **M4-P1-T5** Display authoritative-source claims separately from personal notes and AI suggestions.
- [x] **M4-P1-T6** Evaluate investment guidance against current evidence while allowing factual recording of existing holdings.

## Acceptance criteria

- [x] **M4-P1-AC1** An asset without evidence defaults to pending review and is not presented as verified compliant.
- [x] **M4-P1-AC2** Conflicting current assessments produce a visible conflict and no automatic compliant recommendation.
- [x] **M4-P1-AC3** A passed review date shows overdue status; it does not silently renew certification.
- [x] **M4-P1-AC4** Replacing an assessment retains previous evidence, author and effective dates for as-of views.
- [x] **M4-P1-AC5** A manually recorded holding can exist with any status, but decision prompts explain unresolved compliance risks.
