# M3-P3 - Valuation and currency-aware performance

**Milestone:** M3 - Investments and valuation
**Dependencies:** M3-P2, human accepted; M2 milestone accepted.
**Current status:** IN_PROGRESS, cycle 1 of at most six. One implementation owner;
independent technical/rendered review and all actual M3-P3 gates pending.

## Description and goal

Value investments from dated observations and distinguish market movement from
currency effects. Provide reproducible, clearly labeled performance without
silently filling missing prices. Distinguish return, monetary gain, contributions
and FX effects. Do not manufacture live market values.

## Task checklist

- [ ] **M3-P3-T1** Create manual price observations with source, currency, effective time and immutable version references.
- [ ] **M3-P3-T2** Calculate native market value, cost, realized/unrealized gains and income with explicit missing-data states.
- [ ] **M3-P3-T3** Translate cost using transaction-time FX and value using valuation-time FX; preserve observation IDs used.
- [ ] **M3-P3-T4** Implement asset, currency, geography and account allocation with completeness indicators.
- [ ] **M3-P3-T5** Use simple percentage return only for supported no-external-flow periods; label cash-flow-adjusted metrics deferred.
- [ ] **M3-P3-T6** Add reproducible valuation runs and caching with owner, cutoff and data-version keys.

## Acceptance criteria

Exact canonical fixtures remain private. Separately reviewed public synthetic
translations preserve the calculation and lifecycle requirements under these IDs.

- [ ] **M3-P3-AC1** A supported no-external-flow period preserves the canonical opposing native and base-currency return results using exact dated FX evidence.
- [ ] **M3-P3-AC2** A missing asset price marks total valuation partial; an unavailable holding is not valued at zero.
- [ ] **M3-P3-AC3** A newer observation cannot leak into a historical valuation; saved runs retain their referenced inputs.
- [ ] **M3-P3-AC4** Aggregate-value accounts and detailed holdings are counted once; known allocation weights reconcile to their stated denominator.
- [ ] **M3-P3-AC5** A period containing unsupported cash flows does not display a misleading percentage labeled total return.

## Deliverables and verification

Price observations, valuation service, allocation/performance views and
reproducibility tests. Verify FX-adjusted return, partial price coverage, as-of
cutoffs, cache isolation and no-double-count behavior. All global invariants
and the verification contract apply. Actual desktop/mobile review, full uncached
and TIA evidence remain separate mandatory gates.

## Scope exclusions and completion boundary

No TWR/XIRR, benchmark forecasts, live feeds or guaranteed-return projections.
Stop at READY_FOR_REVIEW or a documented blocker; only the human accepts. Formal
independent M3 milestone review runs only after every M3 phase is individually
accepted. No M4, main/stage changes, deployment, new credentials or security changes.
The exact canonical phase and prompt are retained privately. See
[run evidence](../runs/M3-P3-local.md).
