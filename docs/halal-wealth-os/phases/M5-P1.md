# M5-P1 - Dashboard and explainable next actions

**Milestone:** M5 - Dashboard and personal V1 release
**Dependencies:** M4-P3. When crossing milestones, the previous milestone gate must also be accepted.
**Initial status:** PLANNED. Owner authorization and dependency acceptance determine readiness.

## Description

Assemble the financial domains into a useful home screen without adding AI or external dependencies.

## Goal

Answer wealth, protection, available cash, allocation and required-action questions from trusted records.

## Task checklist

- [x] **M5-P1-T1** Show reconciled native/base net worth, liabilities, liquid cash, funded goals and investment value.
- [x] **M5-P1-T2** Expose valuation timestamps, missing observations and links from totals to source records.
- [x] **M5-P1-T3** Add deterministic next-action rules for reconciliation, missed funding, evidence reviews and allocation drift.
- [x] **M5-P1-T4** Make rules configurable, deduplicated, explainable and dismissible with a clear data basis.
- [x] **M5-P1-T5** Create reproducible dated snapshots referencing ledger cutoff, quotes and calculation version.
- [x] **M5-P1-T6** Keep the first release functional without bank, market-data, Google or AI credentials.

## Acceptance criteria

- [x] **M5-P1-AC1** Every headline total drills down to owner-scoped underlying records and a stated as-of cutoff.
- [x] **M5-P1-AC2** Cash, IPO receivables, holdings and aggregate accounts are not double counted; liabilities reduce net worth once.
- [x] **M5-P1-AC3** A missing quote/rate marks the relevant widget partial instead of displaying a fabricated total.
- [x] **M5-P1-AC4** An emergency standing order already marked configured does not generate an unsolicited duplicate reminder.
- [x] **M5-P1-AC5** An action explains its trigger and threshold; rerunning rules at the same state does not create duplicates.

## Deliverables

Dashboard; next-action rules; snapshot service; manual-first integrated demo.

## Verification emphasis

Net-worth reconciliation, source drill-down, snapshot reproducibility, action dedupe and offline-provider tests.

All applicable global invariants and the verification contract also apply. Use the run template to record observed evidence; a checklist tick alone is not proof.

## Scope exclusions

AI chat, external notifications, live prices and automatic financial decisions.

AGENTS and the phase runbook govern execution and publication. No later phase,
deployment or external financial action is authorized.
