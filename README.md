# Halal Wealth OS

A planned personal wealth tracking, planning and decision-support application. The intended architecture is a Laravel modular monolith with Inertia, Vue 3, TypeScript, PostgreSQL and restricted Filament administration.

This checkout contains a local M0-P1 planning package only. No application has been scaffolded, no runtime compatibility has been accepted, and no implementation execution is authorized by this document. Public source visibility does not change the private personal product scope.

Start with [the planning index](docs/halal-wealth-os/INDEX.md), [scope](docs/halal-wealth-os/SCOPE.md), [repository audit](docs/halal-wealth-os/REPOSITORY-AUDIT.md) and [M0-P1 review evidence](docs/halal-wealth-os/runs/M0-P1-local.md).

The human owner accepted M0-P1 and the six ADR directions and authorized publication of the independently reviewed sanitized planning package. See [the acceptance boundary](docs/halal-wealth-os/ACCEPTANCE.md). Runtime pins remain candidates; M0-P2 execution and deployment remain blocked.
